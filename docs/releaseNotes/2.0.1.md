### Main improvements in this release:

### Short summary:

This release contains three sets of changes:
- Structural model changes that were previously already approved, but did not make it into the 2.0.0 release in time.
  -  [#929](https://github.com/SysBioChalmers/Human-GEM/issues/929), [#934](https://github.com/SysBioChalmers/Human-GEM/issues/934), [#943](https://github.com/SysBioChalmers/Human-GEM/issues/943), [#944](https://github.com/SysBioChalmers/Human-GEM/issues/944), [#945](https://github.com/SysBioChalmers/Human-GEM/issues/945), [#991](https://github.com/SysBioChalmers/Human-GEM/issues/991), [#994](https://github.com/SysBioChalmers/Human-GEM/issues/994), [#995](https://github.com/SysBioChalmers/Human-GEM/issues/995)
- Non-structural model changes, mostly regarding:
  - Updated annotations to various databases
  - Reconciling metabolite formula/InChI/SMILES, so that all are at pH 7.3 (this leaves various mass- and charge-unbalanced reactions, as visible in the test results, but this will be resolved in an upcoming release, as it will introduce more structural changes and it would be good to systematically track the performances of these with the new tests (see below))
  - Assign standardized names to all metabolites and standardize reaction names
  - Add and correct EC numbers
  - **None of these recent changes make structural changes to the model**: [#1019](https://github.com/SysBioChalmers/Human-GEM/issues/1019), [#1029](https://github.com/SysBioChalmers/Human-GEM/issues/1029), [#1032](https://github.com/SysBioChalmers/Human-GEM/issues/1032), [#1034](https://github.com/SysBioChalmers/Human-GEM/issues/1034), [#1035](https://github.com/SysBioChalmers/Human-GEM/issues/1035), [#1036](https://github.com/SysBioChalmers/Human-GEM/issues/1036), [#1048](https://github.com/SysBioChalmers/Human-GEM/issues/1048), [#1051](https://github.com/SysBioChalmers/Human-GEM/issues/1051), [#1052](https://github.com/SysBioChalmers/Human-GEM/issues/1052), [#1053](https://github.com/SysBioChalmers/Human-GEM/issues/1053), [#1054](https://github.com/SysBioChalmers/Human-GEM/issues/1054), [#1057](https://github.com/SysBioChalmers/Human-GEM/issues/1057), [#1058](https://github.com/SysBioChalmers/Human-GEM/issues/1058)
- Improvements and maintenance of the Human-GEM repo, mostly regarding:
  - All tests run via GitHub Actions (no self-hosted runners) through python, making use of new raven-toolbox package.
  - Cutting a release (bumping the version, regenerating `model/Human-GEM.mat/.xml/.xlsx/.txt`) is now done via `code/io/increaseHumanGEMVersion.py` (Python + `raven-toolbox`), replacing the old MATLAB/RAVEN script.
  - Complete redesign of tests that are run in each PR, or can be triggered by commenting `/run memote` or `/run gene-essentiality` (this will only start working once the current PR is merged to main), reproducible `ftINIT` tests of Hart 2015-dataset, tracking of test outputs so that changes are easily visible.
  - Removal of old scripts and functions that have become obsolete, also remove database dumps that have become outdated. Note that all old files remain available through old Human-GEM releases.
  - Overhauled contributor tracking and reassigned contributions to fewer categories to reduce unnecessary complexity (all names of past contributors are retained). 
  - [#997](https://github.com/SysBioChalmers/Human-GEM/issues/997), [#1008](https://github.com/SysBioChalmers/Human-GEM/issues/1008), [#1024](https://github.com/SysBioChalmers/Human-GEM/issues/1024), [#1025](https://github.com/SysBioChalmers/Human-GEM/issues/1025), [#1027](https://github.com/SysBioChalmers/Human-GEM/issues/1027), [#1031](https://github.com/SysBioChalmers/Human-GEM/issues/1031), [#1035](https://github.com/SysBioChalmers/Human-GEM/issues/1035), [#1045](https://github.com/SysBioChalmers/Human-GEM/issues/1045), [#1046](https://github.com/SysBioChalmers/Human-GEM/issues/1046), [#1049](https://github.com/SysBioChalmers/Human-GEM/issues/1049), [#1052](https://github.com/SysBioChalmers/Human-GEM/issues/1052), [#1055](https://github.com/SysBioChalmers/Human-GEM/issues/1055), [#1059](https://github.com/SysBioChalmers/Human-GEM/issues/1059), [#1064](https://github.com/SysBioChalmers/Human-GEM/issues/1064)
